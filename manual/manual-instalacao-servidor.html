Requisitos do Servidor

O sistema HAUXHAUX é uma aplicação Next.js 15 com banco de dados PostgreSQL. Os requisitos mínimos para rodar em produção são:

🖥️ Sistema Operacional

Ubuntu 22.04 LTS ou 24.04 LTS (recomendado)
Debian 11 ou 12 também funciona

⚡ CPU e RAM

Mínimo: 1 vCPU / 1 GB RAM
Recomendado: 2 vCPU / 2 GB RAM

💾 Disco

Mínimo: 10 GB livres
Recomendado: 20 GB SSD

🌐 Rede

IP público fixo
Portas 80 e 443 abertas no firewall

Softwares necessários

Software Versão Função
Node.js 20.x LTS Executar a aplicação Next.js
npm 10+ Gerenciador de pacotes (vem com Node.js)
PostgreSQL 14, 15 ou 16 Banco de dados (OU usar Neon.tech)
PM2 Última versão Processo manager / auto-restart
Nginx 1.18+ Proxy reverso + SSL
Certbot Última versão Certificado SSL gratuito (Let's Encrypt)
Git 2.x Clonar o repositório
ℹ️ Banco de dados: O sistema está configurado para usar o Neon.tech (PostgreSQL na nuvem). Se preferir usar um PostgreSQL local no servidor, veja a Seção 4. Caso mantenha o Neon, pule a parte de instalação do PostgreSQL.
2

Preparação do Servidor (Ubuntu/Debian)

Acesse o servidor via SSH e execute os comandos abaixo como usuário root ou com sudo.

2.1 Atualizar o sistema

Terminal — SSH no servidor
$ sudo apt update && sudo apt upgrade -y

2.2 Instalar dependências básicas

Terminal
$ sudo apt install -y git curl wget build-essential nginx certbot python3-certbot-nginx

2.3 Configurar Firewall (UFW)

Terminal
$ sudo ufw allow ssh $ sudo ufw allow 80 $ sudo ufw allow 443 $ sudo ufw enable $ sudo ufw status

2.4 Criar usuário para a aplicação (boa prática)

Terminal
$ sudo adduser hauxhaux $ sudo usermod -aG sudo hauxhaux # Troque para o usuário hauxhaux para os próximos passos $ su - hauxhaux
3

Instalação do Node.js 20

Use o NodeSource para instalar o Node.js 20 LTS (a versão mais compatível com o Next.js 15).

Terminal — instalar Node.js 20 via NodeSource
# Adicionar repositório do NodeSource $ curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - # Instalar o Node.js $ sudo apt install -y nodejs # Verificar versões instaladas $ node --version # Esperado: v20.x.x $ npm --version # Esperado: 10.x.x

Instalar PM2 (gerenciador de processos)

Terminal
$ sudo npm install -g pm2
4

Configuração do Banco de Dados

✅ Opção A (Recomendada — já configurada): O banco de dados está hospedado no Neon.tech (PostgreSQL na nuvem). A string de conexão será fornecida pelo contratante. Nesse caso, pule esta seção inteira e vá direto para a Seção 5.
ℹ️ Opção B — PostgreSQL local: Se preferir usar um banco de dados no próprio servidor, siga os passos abaixo.

4.1 Instalar PostgreSQL

Terminal — apenas se usar banco LOCAL
$ sudo apt install -y postgresql postgresql-contrib # Iniciar e habilitar o serviço $ sudo systemctl start postgresql $ sudo systemctl enable postgresql

4.2 Criar banco e usuário

Terminal
$ sudo -u postgres psql -- Dentro do psql: CREATE DATABASE hauxhaux; CREATE USER hauxhaux_user WITH PASSWORD 'SUA_SENHA_FORTE_AQUI'; GRANT ALL PRIVILEGES ON DATABASE hauxhaux TO hauxhaux_user; \q

Nesse caso a sua DATABASE_URL será:

String de conexão local
postgresql://hauxhaux_user:SUA_SENHA@localhost:5432/hauxhaux
5

Download do Código-Fonte

Clone o repositório do GitHub para o servidor:

Terminal — clonar o repositório
# Ir para o diretório de aplicações $ cd /home/hauxhaux # Clonar o repositório $ git clone https://github.com/sourenato/hauxhaux-app.git # Entrar na pasta do projeto $ cd hauxhaux-app # Verificar os arquivos $ ls -la

Instalar dependências do projeto

Terminal — dentro da pasta hauxhaux-app
# Instalar todos os pacotes Node.js $ npm install # Aguarde o download terminar (pode levar 2-3 minutos)
⚠️ Atenção: O comando npm install pode demorar alguns minutos na primeira vez. Não interrompa o processo.
6

Configuração das Variáveis de Ambiente

As variáveis de ambiente contêm as configurações sensíveis do sistema (banco de dados, autenticação, URL). Nunca suba este arquivo para o GitHub — ele fica apenas no servidor.

6.1 Criar o arquivo .env.local

Terminal — criar arquivo de configuração
$ nano /home/hauxhaux/hauxhaux-app/.env.local

6.2 Conteúdo do .env.local

Cole o conteúdo abaixo no editor, substituindo os valores conforme indicado:

.env.local — arquivo de configuração
# ==================================== # HAUXHAUX — Variáveis de Ambiente # ==================================== # Banco de dados PostgreSQL (string completa fornecida pelo contratante) DATABASE_URL="postgresql://neondb_owner:SENHA@HOST/neondb?sslmode=require" # Secret JWT — gere um valor único com o comando abaixo: # openssl rand -base64 32 NEXTAUTH_SECRET="COLE_AQUI_O_SECRET_GERADO" # URL pública do sistema NEXTAUTH_URL="https://gestao.hauxhaux.com.br"
⚠️ Salvar no nano: Após colar o conteúdo, pressione Ctrl+X, depois Y (sim), depois Enter para salvar.

6.3 Gerar o NEXTAUTH_SECRET

Terminal — gerar secret seguro
$ openssl rand -base64 32 # Copie o resultado e cole no .env.local acima

6.4 Verificar permissões do arquivo

Terminal
$ chmod 600 /home/hauxhaux/hauxhaux-app/.env.local

Build e Inicialização do Sistema

7.1 Aplicar o schema no banco de dados

Terminal — dentro da pasta hauxhaux-app
# Gerar o Prisma Client $ npx prisma generate # Aplicar o schema no banco (cria as tabelas) $ npx prisma db push # Esperado: mensagens de "Your database is now in sync with your Prisma schema"

7.2 Popular dados iniciais

Terminal
# Criar usuário admin e categorias iniciais $ npx prisma db seed # Esperado: # ✅ Admin user: admin@hauxhaux.com.br # ✅ Categorias iniciais criadas # 🎉 Seed completo!

7.3 Fazer o build de produção

Terminal — este passo pode demorar 3-5 minutos
$ npm run build # Ao final deve aparecer algo como: # ✓ Compiled successfully # Route (app) Size First Load JS

7.4 Testar se o sistema sobe

Terminal — teste rápido (Ctrl+C para parar depois)
$ npm start # Acesse http://IP_DO_SERVIDOR:3000 para verificar # Ctrl+C para parar após verificar

Configuração do PM2 (Auto-restart)

O PM2 garante que o sistema reinicie automaticamente em caso de falha ou reboot do servidor.

8.1 Iniciar com PM2

Terminal — dentro da pasta hauxhaux-app
# Iniciar a aplicação com PM2 $ pm2 start npm --name "hauxhaux" -- start # Verificar se está rodando $ pm2 status

8.2 Configurar para reiniciar no boot do servidor

Terminal
# Gerar script de startup (siga as instruções que aparecerem) $ pm2 startup # ATENÇÃO: copie e execute o comando que o PM2 mostrar, ex: # sudo env PATH=$PATH:/usr/bin /usr/local/lib/node_modules/pm2/bin/pm2 startup systemd -u hauxhaux --hp /home/hauxhaux # Salvar configuração atual $ pm2 save

8.3 Verificar logs

Terminal
# Ver logs em tempo real $ pm2 logs hauxhaux # Ver últimas 50 linhas $ pm2 logs hauxhaux --lines 50

Configuração do Nginx (Proxy Reverso)

O Nginx recebe as requisições na porta 80/443 e as redireciona para a aplicação Next.js na porta 3000.

9.1 Criar arquivo de configuração do site

Terminal
$ sudo nano /etc/nginx/sites-available/hauxhaux

9.2 Conteúdo da configuração Nginx

/etc/nginx/sites-available/hauxhaux
server { listen 80; server_name gestao.hauxhaux.com.br; location / { proxy_pass http://localhost:3000; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection 'upgrade'; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; proxy_cache_bypass $http_upgrade; proxy_read_timeout 300s; proxy_connect_timeout 75s; } }

9.3 Ativar o site e reiniciar Nginx

Terminal
# Ativar o site $ sudo ln -s /etc/nginx/sites-available/hauxhaux /etc/nginx/sites-enabled/ # Testar configuração (deve mostrar "test is successful") $ sudo nginx -t # Reiniciar Nginx $ sudo systemctl restart nginx $ sudo systemctl enable nginx
10

Certificado SSL com Let's Encrypt

⚠️ Pré-requisito: O DNS do domínio gestao.hauxhaux.com.br deve estar apontando para o IP do servidor ANTES de executar este passo. Veja a Seção 11 para configurar o DNS primeiro.

10.1 Emitir certificado SSL gratuito

Terminal — substitua pelo seu e-mail
# Emitir e instalar o certificado automaticamente $ sudo certbot --nginx -d gestao.hauxhaux.com.br --email SEU_EMAIL@gmail.com --agree-tos --non-interactive # Durante o processo: # - Aceitar os termos automaticamente com --agree-tos # - Certbot modificará o Nginx para usar HTTPS automaticamente

10.2 Verificar renovação automática

Terminal
# Testar renovação automática $ sudo certbot renew --dry-run # Esperado: "Congratulations, all simulated renewals succeeded"
✅ Resultado: Após este passo, o sistema estará acessível via https://gestao.hauxhaux.com.br com cadeado verde.

Configuração de DNS

O DNS deve ser configurado no painel do registrador do domínio hauxhaux.com.br. Esta etapa é responsabilidade do proprietário do domínio ou do seu técnico de DNS.

Registro a adicionar

Tipo Nome Valor TTL
A gestao IP_DO_SERVIDOR (ex: 191.252.100.50) 3600 (1h)
ℹ️ Propagação de DNS: Após criar o registro, aguarde de 5 minutos a 24 horas para propagação. Você pode verificar em: https://dnschecker.org

Como verificar se o DNS está propagado

Terminal — no servidor
$ nslookup gestao.hauxhaux.com.br # Deve mostrar o IP do servidor # Ou via ping: $ ping gestao.hauxhaux.com.br

Verificação Final e Testes

Execute este checklist final para confirmar que tudo está funcionando:

Checklist de verificação

  1. Acesse https://gestao.hauxhaux.com.br no navegador — deve abrir a tela de login com cadeado verde (HTTPS)
  2. Faça login com admin@hauxhaux.com.br / hauxhaux@admin2024
  3. Verifique se o Dashboard carrega os indicadores corretamente
  4. Acesse pelo menos uma sub-página (ex: Produtos) e verifique se os dados carregam
  5. Teste o Portal do Parceiro: faça logout e entre com a conta de parceiro
  6. Verifique se o PM2 está rodando: pm2 status deve mostrar online
  7. Faça um reboot do servidor (sudo reboot) e verifique se o sistema volta automaticamente
✅ Sistema pronto! Se todos os itens acima passaram, o sistema está funcionando em produção.

Solução de Problemas Comuns

❌ Erro: "502 Bad Gateway"

Causa: A aplicação Next.js não está rodando na porta 3000.
Solução
$ pm2 status # Verificar se está "online". Se estiver "stopped" ou "errored": $ pm2 restart hauxhaux $ pm2 logs hauxhaux # Verifique o erro nos logs

❌ Erro: "Application error: a client-side exception has occurred"

Causa: Variável de ambiente faltando ou incorreta.
Solução
# Verificar se o .env.local existe e tem os campos corretos: $ cat /home/hauxhaux/hauxhaux-app/.env.local # Após corrigir, rebuild e reiniciar: $ npm run build && pm2 restart hauxhaux

❌ Erro: "PrismaClientInitializationError" / "Connection refused"

Causa: String de conexão do banco incorreta ou banco inacessível.
Solução
# Testar a conexão com o banco: $ npx prisma db push # Se falhar, verifique a DATABASE_URL no .env.local

❌ Erro: "Port 3000 already in use"

Solução
# Verificar o que está usando a porta 3000: $ sudo lsof -i :3000 # Matar o processo: $ sudo kill -9 PID_DO_PROCESSO $ pm2 start npm --name "hauxhaux" -- start

❌ Certificado SSL não renova automaticamente

Solução
# Renovar manualmente: $ sudo certbot renew $ sudo systemctl restart nginx
